## 🔑 签名密钥

签名密钥用于发布版APK签名，必须妥善保管。

1. 在项目根目录执行（密码自己定）：
```bash
keytool -genkeypair -v \
  -keystore release/teleprompter_release.jks \
  -keyalg RSA -keysize 2048 -validity 10000 \
  -alias teleprompter \
  -storepass 你的密钥库密码 \
  -keypass 你的密钥密码
```

2. 将密码填入 `release/signing.properties`

3. ⚠️ **务必备份 .jks 文件和密码！丢失后无法更新应用**

4. 构建签名APK：
```bash
cd app
../gradlew assembleRelease
```
输出：`app/build/outputs/apk/release/app-release.apk`
