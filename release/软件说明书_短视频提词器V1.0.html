短视频提词器 V1.0 软件说明书


一、软件概述


软件名称：短视频提词器

版本号：V1.0

开发语言：Kotlin

运行平台：Android 7.0（API 24）及以上

软件类型：工具类应用


短视频提词器是一款专为自媒体创作者设计的Android应用，将前置摄像头录制与提词器功能合二为一。用户在录制口播视频时，提词文字以半透明方式悬浮在屏幕上方（靠近前摄像头位置），实现自然看词的效果，避免眼神偏移。同时提供广角畸变校正功能，让前置摄像头拍摄的画面更加自然。


二、功能说明


2.1 前置摄像头高清录制

  • 支持1080P（1920×1080）前置摄像头录制
  • 录制视频为纯净画面，不含提词文字叠加
  • 支持录制计时显示

    • 2.2 半透明提词器

  • 提词文字以半透明方式悬浮在屏幕上方
  • 文字位置靠近前摄像头，看词时眼神方向自然
  • 支持从其他应用复制粘贴提词内容
  • 自动滚动，播放/暂停/回到顶部控制

    • 2.3 字体调节

  • 字体大小：12sp ~ 40sp，连续可调
  • 透明度：20% ~ 100%，连续可调
  • 滚动速度：可调

    • 2.4 广角畸变校正

  • 默认1.4x数字变焦，减小前置广角畸变
  • 变焦范围：1.0x ~ 3.0x，步进0.2x
  • 控制栏提供缩放按钮（🔍+/🔍-）和倍率显示

    • 2.5 录制控制

  • 开始/停止录制按钮
  • 录制计时实时显示
  • 控制栏3秒自动隐藏，轻触屏幕重新显示

    • 2.6 隐私合规

  • 首次启动显示隐私政策弹窗，用户需同意后方可使用
  • 不收集、不上传、不分享任何用户数据
  • 无广告、无追踪

    • 三、运行环境


    项目 要求
    操作系统 Android 7.0（API 24）及以上
    存储 约3.5MB安装空间
    摄像头 前置摄像头（必需）
    权限 相机权限、录音权限、存储权限

    四、操作说明


    4.1 首次启动

    1. 安装APK后点击应用图标启动

    2. 首次启动显示隐私政策弹窗

    3. 阅读隐私政策后点击"同意并继续"进入主界面


    4.2 输入提词内容

    1. 点击编辑按钮（✏️图标）

    2. 在文本框中输入或粘贴提词内容

    3. 点击确定保存


    4.3 调节提词参数

  • 字体大小：点击字体放大/缩小按钮调节
  • 透明度：滑动透明度滑块调节
  • 滚动速度：滑动速度滑块调节

    • 4.4 调节缩放

  • 点击🔍+按钮放大（减小畸变）
  • 点击🔍-按钮缩小（恢复广角）
  • 倍率显示在控制栏中

    • 4.5 开始录制

    1. 确认提词内容已输入

    2. 点击录制按钮（红色圆点）开始录制

    3. 提词文字自动开始滚动

    4. 控制栏3秒后自动隐藏

    5. 轻触屏幕可重新显示控制栏


    4.6 停止录制

  • 点击停止按钮结束录制
  • 视频自动保存到相册

    • 五、技术架构


  • 开发语言：Kotlin
  • 最低SDK：Android 7.0（API 24）
  • 目标SDK：Android 14（API 34）
  • 核心框架：Camera2 API + MediaRecorder
  • 构建工具：Gradle 8.5
  • 代码保护：R8混淆 + ProGuard资源压缩
